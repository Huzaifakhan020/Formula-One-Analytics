# 🏎️ F1 Analytics Dashboard

A modern, premium Formula 1 analytics dashboard showcasing all-time greats, dominant cars, era comparisons, and live 2026 season data.

Features
🏆 Top 10 Drivers of All Time- Historical rankings with championships, wins, poles, and race stats
⚡ Top 5 Cars of All Time- Most dominant F1 cars across different eras
📊 Era Normalizer- Compare drivers from different generations using normalized statistics
🔥 2026 Season- Real-time standings, race results, and championship tracking

Frontend: HTML5, CSS3, JavaScript (Vanilla)
